## 6. Security Findings

- **Authentication & Tokens**: `[CONFIRMED]` Access tokens expire in 15 minutes. Password changes increment `sessionVersion`, revoking all active sessions instantly.
- **IDOR Protection**: `[CONFIRMED]` Fully verified across project, task, milestone, subtask, team, and analytics routes. Unauthorized attempts return `403 Access denied`.
- **Input Sanitization & Rate Limiting**: `[CONFIRMED]` Auth endpoints protected by Express rate limiters. CORS restricted to configured origin. Helmet header security enabled.
- **Socket Security**: `[CONFIRMED]` Handshake validates JWT token. Users automatically joined to `user:${userId}`. Events emitted only to target user rooms.
- **Secrets & Credentials**: `[CONFIRMED]` All secrets (`JWT_SECRET`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `MONGO_URI`) read from `.env`. Zero hardcoded secrets in repository.

---

## 7. Database Findings

- **Model Constraints & Indexes**: `[CONFIRMED]`
  - `RewardEvent`: Compound unique index `{ taskId: 1, reason: 1 }` guarantees reward idempotency.
  - `ActivityEvent`: Indexes on `{ eventType: 1, createdAt: -1 }`, `{ actorId: 1 }`, `{ projectId: 1 }`, `{ taskId: 1 }`.
  - `Task`: Indexes on `{ user: 1 }`, `{ assignedTo: 1 }`, `{ projectId: 1 }`, `{ parentTaskId: 1 }`.
  - `Notification`: Indexes on `{ recipient: 1, read: 1 }`.
- **Unbounded Growth Mitigation**: `[CONFIRMED]` Chat messages stored as standalone documents in `Message` collection with paginated fetches, avoiding unbounded document growth. Soft deletion handled via `deletedAt` timestamps.
