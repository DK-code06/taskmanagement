## 3. Design Tokens Architecture

- **Colors:** Primary (`#3b82f6`), Secondary (`#64748b`), Background (`#f8fafc`), Text Primary (`#0f172a`), Text Secondary (`#334155`), Success (`#16a34a`), Warning (`#d97706`), Danger (`#dc2626`), Info (`#0284c7`). Text colors strictly comply with WCAG 4.5:1 contrast requirement against white/slate paper backgrounds.
- **Typography:** `Inter, system-ui, sans-serif`, font sizes from `xs` (12px) to `3xl` (30px), font weights 400, 500, 600, 700.
- **Spacing:** `xs` (4px), `sm` (8px), `md` (16px), `lg` (24px), `xl` (32px), `2xl` (48px).
- **Radius:** `sm` (4px), `md` (8px), `lg` (12px), `xl` (16px), `full` (9999px).
- **Shadows:** `subtle`, `elevated`, `modal`, `focus`.
- **Z-Index:** `dropdown` (10), `sticky` (20), `modal` (50), `toast` (60), `tooltip` (70).

## 4. Accessibility & Responsive Changes

- **WCAG 2.2 AA Compliance:**
  - Mandatory visible focus rings (`:focus-visible` 2px solid primary color with offset).
  - All icon buttons require `aria-label` or fall back to child text.
  - Modals and Drawers lock body scroll (`overflow: hidden`) and trap focus inside using keyboard Tab/Shift+Tab navigation.
  - Modals and Drawers close on `Escape` key press and restore focus to the triggering element upon unmount.
- **Responsive System:**
  - Viewports verified: `320px`, `375px`, `390px`, `414px`, `480px`, `768px`, `1024px`, `1280px`, `1440px`, `1920px`.
  - Touch targets set to minimum 44px height for interactive buttons and inputs.
  - Mobile layout automatically hides desktop sidebars under 768px and activates the accessible navigation drawer.
