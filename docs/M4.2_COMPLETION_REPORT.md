## 3. Routes Added & APIs Consumed

### A. Routes Added
- `/projects`: Projects Directory page (`ProjectList`).
- `/projects/:projectId`: Project Details & Overview screen (`ProjectOverview`).

### B. APIs Consumed
- `GET /api/projects`: Fetch projects accessible to logged-in user.
- `POST /api/projects`: Create a new project.
- `GET /api/projects/:id`: Fetch single project detail with authorization.
- `PUT /api/projects/:id`: Update project details/status.
- `DELETE /api/projects/:id`: Soft delete / archive project.
- `GET /api/milestones/project/:projectId`: Fetch milestones for a project.
- `POST /api/milestones`: Create a milestone inside a project.
- `PUT /api/milestones/:id`: Update milestone details/status.
- `DELETE /api/milestones/:id`: Soft delete milestone.
- `GET /api/tasks/project/:projectId`: Fetch root tasks for a project.
- `GET /api/tasks/:id/subtasks`: Fetch subtasks under a parent task.
